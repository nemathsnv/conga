# Shortcut app

Expo SDK 57 / React Native / TypeScript / Expo Router, for iOS and Android from one codebase.
Product behaviour comes from `../SPEC.md`; every screen is built from its board in `../design/`.

## Layout

| Path | What it is |
|---|---|
| `src/app/` | Expo Router routes. `(onboarding)` holds sign-in through the photo step; `(tabs)` the five tabs. |
| `src/lib/` | Supabase client, sign-in methods, server calls, session and onboarding state, pure validation rules. |
| `src/ui/` | Theme tokens and primitives taken from the boards (buttons, header, grouped rows, step bar, tab bar, icons). |
| `src/__tests__/` | Jest unit tests for the pure logic. |
| `plugins/` | Config plugins. `withSceneLifecycle.js` adopts the iOS scene lifecycle (needed on iOS 27). |
| `assets/placeholders/` | The board collage and faces. People and photos in the boards are placeholders. |

## Commands

```bash
npm install
cp .env.example .env     # fill in the public values
npm run typecheck
npm run lint
npm test
npm run ios              # build and run on the connected iPhone
npm run android          # build and run on a connected Android device or emulator
```

Native projects (`ios/`, `android/`) are generated by `npx expo prebuild` and are not committed.
CocoaPods needs a UTF-8 locale: `export LANG=en_US.UTF-8` before `pod install` or `npm run ios`.

## Configuration

Only `EXPO_PUBLIC_*` values are bundled; see `.env.example`. Secrets never go here.
Google Sign-In's native config needs `GOOGLE_IOS_URL_SCHEME` at prebuild time; without it the
plugin is skipped and the Google button fails with a configuration error.
`EXPO_PUBLIC_DEV_TOOLS=1` shows a development-only sign-out on the Me tab until Settings exists.
